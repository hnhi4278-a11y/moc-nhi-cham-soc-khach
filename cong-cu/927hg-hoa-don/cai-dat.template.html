Dùng

  1. Mở checkout.30shine.com/danh-sach-hoa-don, đăng nhập, bấm nút — khung xanh hiện góc phải.

  3. Lọc khoảng ngày tháng này đến hôm nay → Tìm kiếm → bấm Kéo hết → tệp LOẠI TRỪ.
  4. Bấm Tải file Excel → file 927HG_CSKH_ngàythángnăm.xlsx (STT / Tên / SĐT / Ngày ghé / Stylist / Skinner / Dịch vụ).
